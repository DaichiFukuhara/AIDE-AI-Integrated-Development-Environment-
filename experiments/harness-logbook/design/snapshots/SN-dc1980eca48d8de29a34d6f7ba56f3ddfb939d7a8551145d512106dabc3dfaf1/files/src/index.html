プロジェクト内でCLIを実行すると、ファイルに保存され、この画面に反映されます。

python src/logbook.py --id EVENT-001 \
  --actor Codex --phase implementation \
  --kind action --title "操作の要約" \
  --body "実際に行ったことと観測結果" \
  --reason "短い判断理由" \
  --next "次に行うこと"

例はシェルに合わせて1行にまとめて実行できます。同じID・同じ内容の再送は重複しません。訂正は新IDで追記します。
