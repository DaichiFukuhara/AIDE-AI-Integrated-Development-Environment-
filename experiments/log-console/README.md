# AIDE Agent Log

AIが「何をしたか・なぜ選んだか・何が残っているか」を記録する、HTML / CSS / JavaScriptだけの実験用ログ画面です。既存のハーネスを変更せず、独立したプロトタイプとして置いています。

## 起動

`index.html` をブラウザで開けます。安定した保存先で使う場合は、このディレクトリで以下を実行してください。

```sh
python -m http.server 4173 --bind 127.0.0.1
```

ブラウザで <http://127.0.0.1:4173> を開きます。ビルドや依存パッケージは不要です。

## 画面の考え方

- **実行ログ**：時系列で操作、判断、検証、未解決事項を読む。
- **判断の記録**：結論と、読み手に説明する短い理由を読む。内部の思考過程の全文記録を目的にしません。
- **成果物**：根拠となるファイル名や記録IDを一覧にする。ファイル本体は未接続です。
- **右側の情報**：実験の目的、完了条件、役割ごとの記録数、次のアクションを表示する。
- **要確認**：`open` または `failed` のイベントを集計する。未実行や記録済みを検証成功として扱いません。

初期データは架空の3セッションです。デモ実行は1.7秒ごとに計3件のサンプルログを追加し、実際のAIやツールは実行しません。実験の成功、独立監査、設計への採用を自動で確定しません。完了条件は読み込んだセッションの設定を表示し、デモで書き換えません。

## 操作

- 検索、種類の絞り込み、重要マーク、時刻順、コンパクト表示。
- サイドバーからセッション切り替え。
- ログ追加、未解決ログの解決記録（変更した事実を別イベントに残す）。
- 選択中の全ログをMarkdownまたはJSONに書き出し。
- 書き出したJSONを新しいセッションとして取り込み。同じIDは別名にして既存データを保持。
- `/` キーで検索にフォーカス。

データはブラウザの `localStorage` に保存します。ブラウザ・URL・ポートが変わると保存領域も変わります。ストレージが利用できない場合は画面に通知し、書き出しで保存できます。複数タブによる同時編集・サーバー保存・自動のファイル追跡は未対応です。

## ハーネスとの接続点

同じページ内で実行するコードは、次のAPIで検証付きのログ追加ができます。外部プロセスから直接接続するAPIサーバーはありません。

```js
window.harnessLog.append({
  id: 'trial-025-check-01', // 省略時は生成。同一セッション内の重複は拒否。
  type: 'check',          // action | decision | check | issue
  agent: 'Reviewer',
  title: '参照先の存在を確認',
  body: '5件の参照先がすべて存在することを確認しました。',
  outcome: 'passed',      // recorded | passed | failed | open | resolved
  reason: '',
  evidence: 'checks/references.json',
  next: '別セッションで作業再開を確認する。'
  // time: ISO 8601（省略時は現在時刻）
});

const session = window.harnessLog.getSession(); // 独立したコピー
```

既存ハーネスからファイルで受け渡す場合は、書き出したJSONと同じ構造を作ります。`example-session.json` をインポートすると、受け渡し用サンプルを試せます。

```json
{
  "version": 1,
  "session": {
    "id": "EXP-025",
    "title": "次の実験",
    "status": "進行中",
    "goal": "今回確かめること",
    "objective": "実験の目的と対象",
    "criteria": [{ "text": "観測で確かめる条件", "done": false }],
    "next": "最初の試行を実施する",
    "events": []
  }
}
```

各イベントの必須項目は `type`, `agent`, `title`, `body`, `time`, `outcome`。取り込みは最大5MB、1セッション5,000イベント、50セッションです。表示時に文字列をエスケープし、根拠のパスや入力HTMLは実行しません。

## 次に試すこと

実際のハーネスの1試行からJSONを作り、未解決事項と次の操作だけを見て作業再開できるか確認する。その結果をもとに、イベント形式やサーバー連携の必要性を決めます。

## プロトタイプの確認記録

2026-09-27 にアプリ内ブラウザで、検索と該当なし表示、種類の絞り込み、判断／成果物の切り替え、重要マークの絞り込み、並び順、手動追加、再読み込み後の保持、解決記録の追記、デモの3件追加、スマートフォン幅でのセッション切り替えを確認しました。デスクトップ幅1,440pxとスマートフォン幅390pxで表示を確認しています。JavaScriptの構文確認とサンプルJSONの構文確認も実施済みです。

ファイル操作のブラウザ検証には制約が残っています。JSON書き出しの操作後に完了イベントを取得できず、取り込みはブラウザ操作の自動承認タイムアウトとファイル選択の期限切れで確認を完了できませんでした。ファイルの保存・再取り込みは通常のブラウザでの確認が必要です。
