これは指摘の受領記録であり、修正完了の記録ではない。各指摘はopenのまま。変更する条件・seamは影響調査の候補で、意味変更を反映済みという意味ではない。

| ID | 修正先の責任 | 解消する状態 |
| --- | --- | --- |
| AV3-001 | G-V3の公開契約、S-RECORD・S-CYCLE・S-AUDIT | 監査対象の仕様・実装・証拠が不変な版集合で特定でき、更新時の旧判定の利用可否が一意に決まる |
| AV3-002 | G-V3の公開契約、S-CYCLE・S-RECORD・S-AUDIT | 採用・不採用・取消と中断を区別し、終了を記録する担当と周期監査を起動する担当・受渡しが明確になる |
| AV3-003 | G-V3の公開契約、S-RECORD・S-CYCLE・S-AUDIT | 取消要求のIDと対象operationが区別され、遅延結果・再送・反映との前後関係の扱いが一意になる |
| AV3-004 | v2検査記録。対象はSG-MODEL・SG-LEARN・SG-ASSURE | 過去manifestを変更せず、不足する入力を固定した新しい訂正検査と旧公開記録の関係を説明できる |
