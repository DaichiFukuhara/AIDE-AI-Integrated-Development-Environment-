- 責任: 実装が足した設計上の決定を検出し、4分類する（判定そのもの）
- 詳細化の対象: 本文1の決定照合ゲートのうち**判定の部分**。4分類の判定規則、証拠位置との対応付け、
  自己申告に頼らない独立照合
- 継承する制約: 根の不変条件1〜4と `boundary_requests` の例外、根の「親に残すもの」1〜15、
  ツール固有機能に依存しないこと（Codex / Claude の双方で回る）、予算（深さ3・子数5）。
  handoff の「親に残すもの」1〜11。とくに 1（分類を増やさず減らさない）、
  2（委任の3条件を緩めない）、4（implement の内部手順や役割定義を作らない。境界契約だけ）
- 割り当てられた受け入れ条件: 分類の網羅 / 自己申告漏れの検出
- uses_seams: `h1.criteria`（`gate` から: 照合対象パケット。閉包そのもの・成果物の差分・決定記録・完全性の保証）
- 提供する seam: `h2.findings`（`gate` へ: 分類結果と証拠位置、または「判定不能」。閉包版参照を必ず含める）
- 親から降りる入力: なし。外部 seam の受信は `gate` が担う
